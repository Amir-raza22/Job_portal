\# Job Portal



A full-stack Job Portal application where students can discover and apply for jobs, while recruiters can create jobs, manage applicants, and update application statuses.



\## Features



\### Authentication

\- Student and recruiter registration

\- Login authentication

\- Password hashing using bcrypt

\- JWT-based authentication

\- Role-based authorization



\### Student

\- Browse available jobs

\- Search jobs

\- Filter by location

\- Sort jobs

\- Pagination

\- View job details

\- Apply for jobs

\- Prevent duplicate applications

\- Track application status



\### Recruiter

\- Create jobs

\- View own jobs

\- Edit jobs

\- Delete jobs

\- View applicants

\- Update application status
